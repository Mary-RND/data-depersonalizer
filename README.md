# Деперсонализатор данных (Data Depersonalizer)

Локальный десктопный инструмент деперсонализации персональных данных в файлах Microsoft Excel (`.xlsx`) и Word (`.docx`). Работает полностью **офлайн**: без интернета, без нейросетей и без внешних сервисов — данные не покидают ваш компьютер.

Учебный проект с нуля: от ТЗ на MVP до тестов и шаблона CI (см. `docs/technical-specification.md`).

## Возможности

### Excel (xlsx)

- **Прямая конвертация** — замена значений выбранных колонок на индексы формата `ИД<номер колонки>_<порядковый номер>` (например, `ИД1_0001`, `ИД2_0001`).
- Сохранение двух файлов: `*_деперсонализированные.xlsx` + ключевая таблица-словарь `*_ключ.xlsx` (колонки «Исходная_колонка», «Индекс», «Исходное_значение»).
- **Обратная конвертация** — восстановление исходных данных по паре «файл + ключ» в `*_восстановлено.xlsx`.
- Пустые ячейки не заменяются; одинаковые значения в одной колонке получают один индекс; исходный файл не изменяется.

### Word (docx)

Автоматический поиск и замена категорий персональных данных по встроенным правилам:

- «Телефоны» — `ИДТЕЛ_0001`;
- «Email» — `ИДЕМЕЙЛ_0001`;
- «Паспортные данные» (серия, номер, код подразделения) — `ИДПАСП_0001`;
- «Реквизиты организации» (ИНН, КПП, ОГРН, ОГРНИП, СНИЛС и др.) — `ИДРЕКВ_0001`;
- «Банковские реквизиты» (р/с, к/с, БИК и др.) — `ИДБАНК_0001`;
- «Адреса» (индекс, регион, город, улица, дом/офис) — `ИДАДРЕС_0001`;
- «Названия компаний» (ООО/АО/ПАО/ИП) — `ИДКОМП_0001`;
- «ФИО» — `ИДФИО_0001`;
- Дополнительные пользовательские значения (произвольные строки) — `ИДДОП_0001`.

Обработка всего документа: тело, таблицы, заголовки и колонтитулы. Пары файлов: `*_деперсонализированные.docx` + ключ `*_ключ.docx.xlsx`; восстановление в `*_восстановлено.docx`. Фиксированный порядок замены категорий исключает попадание токенов внутрь других значений (телефон не «поедает» банковский счёт, паспорт не трогает ИНН).

## Технологии

| Компонент | Технология |
|---|---|
| Язык | Python 3.10+ (проверено на 3.14) |
| GUI | `tkinter` (ttk) |
| Excel | `openpyxl` |
| Word | `python-docx` |
| Тесты | `pytest` |

## Установка и запуск

```bash
pip install -r requirements.txt
python -m depersonalizer
```

или после установки пакета из исходников:

```bash
pip install -e .
depersonalizer
```

## Использование

1. **Excel → прямая конвертация**: выбрать `.xlsx`, отметить чувствительные колонки чекбоксами, подтвердить сводку, указать пути сохранения результата и ключа.
2. **Excel → обратная конвертация**: выбрать деперсонализированный файл и ключ, указать путь сохранения.
3. **Word → прямая конвертация**: выбрать `.docx`, отметить категории, при необходимости добавить свои значения, указать пути сохранения.
4. **Word → обратная конвертация**: выбрать `.docx` и ключ, указать путь сохранения.

Ключ храните отдельно от данных: без него обратное восстановление невозможно.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Покрытие: прямая/обратная конвертация Excel (формат индексов, дедупликация, пустые ячейки, round-trip), маскирование категорий Word и примерочные тесты по критериям приёмки ТЗ (`tests/test_acceptance.py`).

## Ограничения MVP

- Обрабатывается только первый лист `.xlsx`, заголовки в первой строке.
- Замена в Word выполняется на уровне абзаца: форматирование заменённого фрагмента может не сохраниться.
- Ключ хранится без шифрования — храните его отдельно от данных.
- Распознавание ФИО/адресов консервативное: нестандартные формы можно указать как дополнительные значения.
